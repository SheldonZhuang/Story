# 人类进步历程视频 — 设计文档

日期：2026-10-09
状态：已确认设计，待用户审阅本文档

## 目标

一段约 3 分钟的知识科普视频，以“能量与工具”为主线，讲述人类从石器到 AI 的进步，并以推测形式延伸到 2056 年。同一份旁白稿，输出横屏和竖屏两个版本。

| 时长 | 约 180 秒，两个版本时长一致 |

## 内容结构

视觉线索：人类掌握的光和能量逐步增加。火光 → 油灯 → 电灯 → 屏幕 → 聚变之光。画面底部有一条对数时间轴，远古段压缩、现代段展开。

| 编号 | 段落 | 时间点 | 目标时长 |
|------|------|--------|---------|
| S01 | 开场：黑暗中的一点火 | — | 10s |
| S02 | 石器 | 约 330 万年前 | 12s |
| S03 | 用火 | 约 100 万年前 | 12s |
| S04 | 农业 | 约 1.2 万年前 | 12s |
| S05 | 金属与车轮 | 约 5000 年前 | 12s |
| S06 | 蒸汽机 | 1769 年 | 18s |
| S07 | 电力 | 1880 年代 | 18s |
| S08 | 核能 | 1942 年 | 14s |
| S09 | 芯片与互联网 | 1947–1990 年代 | 18s |
| S10 | AI | 2020 年代 | 14s |
| S11 | 未来 30 年 | 2026–2056 | 30s |
| S12 | 结尾 | — | 10s |

每段的实际时长以配音长度为准，目标时长只用来控制旁白字数（约每秒 4 个汉字）。

### 史实与推测的区分

- 远古年代采用学界大致估计，统一标注“约”。
- S11 是推测，不是预言：旁白使用“可能”“如果”等语气；画面改用半透明、虚线风格，与史实段落区分开。
- S11 只选择目前已有明确研发路线的方向：核聚变发电、通用 AI、太空基础设施。

## 技术方案

### 文件结构

```
scripts/human-progress.md         # 旁白稿（中文 + 英文字幕译文，按段落编号）
storyboards/human-progress.md     # 分镜：每段的画面元素与动画
tools/human_progress/
  narration.py   # 读取旁白稿 → edge-tts 逐段合成 → 记录每段时长与字幕时间戳
  scenes.py      # 各段的绘制函数：draw(canvas, t, layout)
  layout.py      # 横竖屏布局参数（字号、时间轴位置、安全区）
  render.py      # 逐帧绘制 → 通过管道交给 FFmpeg 编码
  subtitles.py   # 生成双语 SRT
  music.py       # 合成氛围铺底音
  build.py       # 一键串联全流程，输出两个版本
output/                           # 成片、音频、SRT（不提交到 Git）
```

### 数据流

1. `narration.py` 读取旁白稿，每段生成一个音频文件和一份字幕时间戳，汇总成 `output/timeline.json`。
2. `render.py` 按 `timeline.json` 中每段的时长调用对应场景的 `draw()`，逐帧生成 RGB 图像，通过管道交给 FFmpeg。
3. `subtitles.py` 根据时间戳生成双语 SRT；`music.py` 生成和全片等长的铺底音。
4. FFmpeg 合并画面、旁白、铺底音（压低到旁白下方约 -18dB），并烧录字幕。
5. 同一份 `timeline.json` 分别配合两套布局渲染，从机制上保证两个版本时长一致。

### 依赖

- Python 3.13：Pillow、NumPy、edge-tts（固定版本，装在项目内的 `.venv`）
- FFmpeg 9.0（已安装）
- 字体：系统自带的微软雅黑（`C:\Windows\Fonts\msyh.ttc`）

## 错误处理

- edge-tts 调用失败时重试 3 次；仍然失败就停止并提示，可以改用 Windows 离线语音（pyttsx3）作为备选。
- 某一段的实际配音时长偏离目标超过 50% 时给出警告，提示调整旁白字数。
- 所有中间产物缓存在 `output/cache/`，改动单个场景时不需要重新合成全部配音。

## 验证

- 每个场景截取开头、中间、结尾三帧关键帧，人工检查横竖屏排版（文字不越界、不被字幕遮挡）。
- 用 ffprobe 确认两个版本时长一致，误差在 0.1 秒以内。
- 抽查字幕和配音的同步情况，偏差在 0.3 秒以内。
- 交付前把两个成片完整看一遍。
